# Sky Log · 천체관측 도장깨기

## 구성
- Messier 110
- Non-Messier 60
- Stars 42
- 장비별 기록
- Night Vision + Dim
- JSON/CSV 백업
- PWA / 오프라인 캐시

## GitHub Pages
1. GitHub 새 저장소 생성
2. 이 폴더의 파일을 저장소 최상위에 업로드
3. Settings → Pages → Deploy from a branch
4. main / root 선택 후 Save
5. 생성된 Pages 주소를 Safari에서 열기
6. 공유 → 홈 화면에 추가

기록은 기기별 브라우저 localStorage에 저장되므로 가끔 JSON 백업을 권장. 예전 Messier-only JSON도 불러오면 자동 변환함.
